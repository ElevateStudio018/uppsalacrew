Uppsala Crew IF · Sedan 2022

Skateboard, snowboard och freeski i Uppsala

Uppsala Crew arbetar för bättre förutsättningar att åka skateboard, snowboard och freeski i Uppsala. Vi finns till för dig som åker för skojs skull och för dig som vill träna, utvecklas och tävla på elitnivå.
